2. **Additional Photos / Screenshots:**
   - `pcb-layout.png` (EasyEDA / KiCAD schematic or PCB 2-layer design)

   - `wokwi-simulation.png` (Virtual simulation testbench)
   - `telemetry-dashboard.png` (MQTT broker / cloud dashboard status)

Whenever you add photos here, tell Antigravity and their titles/captions will be automatically configured in `src/data/projects.ts`!

# Document Storage Folder

Place your resume / CV and professional reports in this directory:

### Expected Filenames:
1. **Resume / CV**:
   - File: `Emmanuel_Atakos_CV.pdf`
   - Linked from:
     - **Skills & Credentials Page (`/about`)** under *Downloadable Documents & Online Profiles* -> `CV / Resume` button.
     - **Navbar** -> `Download CV` button.

2. **Project Experience Report** *(Optional)*:
   - File: `Emmanuel_Atakos_Project_Experience_Report.pdf`
   - Linked from:
     - **Experience Page (`/experience`)** -> `Download Project Experience Report` button.
     - **Skills & Credentials Page (`/about`)** -> `Project Experience Report` button.

---
> **Note**: Vite serves any files placed in `public/docs/` directly at the URL `/docs/<filename>`.

Personal engineering portfolio website of **Emmanuel Thomas Atakos**, an EBK Registered Graduate Engineer (B25236) specializing in utility-scale & commercial Solar PV systems, LiFePO4 Battery Energy Storage (BESS), EV charging infrastructure, and Industry 4.0 IoT telemetry.

🌐 **Live Demo:** [emmanuelatakos.dev](https://emmanuelatakos.dev)

---

## ⚡ Highlights

- **1.65+ MWp** Solar PV capacity deployed (including 1.4 MWp 1,500 VDC utility grid-tied)
- **500+ kWh** LiFePO4 battery storage commissioned across commercial microgrids
- **50+** IoT telemetry nodes and edge gateways deployed (Modbus RTU / MQTT / Python)
- **7+** Commercial and industrial installations delivered across Kenya

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide React
- **Routing & State:** React Router v7, Context API (Dark/Light theme with persistent storage)
- **Deployment:** Vercel (Edge SPA configuration with `vercel.json`)

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Atakos254/Work-Portfolio.git
cd Work-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## ⚙️ Getting Started Locally

### Prerequisites
- **Node.js**: Version `18.0.0` or higher
- **npm** or **pnpm** / **yarn**

### 1. Clone the Repository
```bash
git clone https://github.com/Atakos254/Work-Portfolio.git
cd Work-Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with Hot Module Replacement (HMR).

### 4. Build for Production
```bash
npm run build
```
Generates an optimized, tree-shaken static production bundle in the `dist/` directory.

### 5. Preview Production Build
```bash
npm run preview
```

### 6. Lint Code
```bash
npm run lint
```

## 🌐 Deployment

The application is optimized for zero-configuration static deployment on **Vercel**, **Netlify**, or **GitHub Pages**.

A `vercel.json` configuration file is included for SPA route rewriting:
```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```
